# 千问生图与参考图

选择千问 Image 2.1（Pro、Turbo）或 3.0（Pro、标准版）后，同一个模型处理纯文字生图和参考图编辑。旧配置中的万相参考图模型不会覆盖这个选择；参考图不受所选模型支持时会报错，不会自动换模型。

配置百炼同地域的 API Key 与 `dashscope_base_url`。北京地址可用 `https://dashscope.aliyuncs.com/api/v1`，也可使用自己的北京业务空间地址。调用官方同步接口 `/services/aigc/multimodal-generation/generation`，每次生成一张图片。

参考图可以从面板参考图库选择；也接受本地文件或公开 HTTP(S) 图片。本包对 2.1 接受最多十张，对 3.0 接受最多三张，按选择顺序编号。调用负责撰写画面提示词的主模型之前，程序检查数量、实际图片格式、完整解码、每张不超过 10 MB、边长 1–8000 像素和宽高比不超过 10:1。图片由实际格式生成 MIME 数据，不把本机文件路径交给服务器。公开参考图先下载并做相同检查，下载不携带百炼密钥。

大于等于 512 KiB 的静态不透明 RGB 或灰度图会尝试高品质 JPEG 编码，仅在结果更小时用于本次传输。像素尺寸与本地原文件保持不变。含透明色、动画或依赖方向标记的图片仍传原编码。连接及上传的时限随参考图实际传输量调整，总时限仍受面板设置约束。

默认输出 `1024*1024`。可以填写 `auto` 让模型选择，或设置面积在 512²–2048²、宽高比不超过 8:1 的宽高；支持 `1K`、`2K`，不自动降级不支持的 `4K`。

负责撰写画面提示词的主模型读取角色卡、用户意图、参考图用途说明，以及调用方提供的共享拟真方案与相关记录。聊天和朋友圈记录保留核验后的真实微信 ID、消息 ID 与来源；不混入无关联系人的记录。上下文超限时按整条旧记录做本地选择，不截断当前任务的 JSON，也不额外付费摘要。可以创作角色世界观内的艺术场景，不把画面编造成真实发生的线下经历。参考图不交给额外识图模型，聊天与朋友圈识图仍使用主模型。

没有相关聊天上下文时，当前任务、参考图用途和角色提示也使用同一完整 JSON 预算检查，包含系统提示、角色卡与主模型输出预留；当前内容无法完整放入时，在调用任何付费模型前报错。交给千问生图的最终提示词另外限制为 4,500 token 的保守估算上限，以 UTF-8 字节长度作为较宽的上界，不是供应商精确 tokenizer，也不是 4,500 字符。超过上限时明确拒绝，不静默截断画面要求，不自动调用付费模型重写。

生图模型自身支持提示词增强与思考开关：`tools_image_prompt_extend`、`tools_image_prompt_extend_mode`、`tools_image_enable_thinking`。思考仅在增强开启时生效；参考图编辑只支持 `direct` 增强模式。`tools_image_watermark` 默认关闭。请求默认时限 600 秒，由 `tools_image_timeout` 调整。

程序在提示词请求、生图请求和下载前后核验取消状态。取消或过时的结果不会发出；已提交的远端生图无法保证取消费用。失败与超时不会自动重试付费请求。图片下载沿用现有的大小、格式和缓存保护，密钥与签名结果地址不会写入错误日志。

接口依据：[阿里云千问图像生成与编辑 API 文档](https://help.aliyun.com/zh/model-studio/qwen-image-generation-and-editing-api-reference)，核验日期：2026-10-12。本适配的合约测试使用模拟 HTTP 与合成图片，不代表已完成用户账号的付费生图实测。
