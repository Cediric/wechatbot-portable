# 生图与参考图

在面板「生图与参考图」中选择生图模型，填写同一地域的百炼 API 地址和密钥。主模型根据角色卡、用户要求和参考图用途编写提示词，再交给选定的生图服务。生成的图片可以用于聊天或朋友圈。

## 使用参考图

1. 从面板参考图库选择图片，也可提供本地文件或公开 HTTP(S) 图片地址。给每张图写清用途，例如“第一张参考人物外貌，第二张参考摄影风格”。
2. 选择支持参考图的模型。当前适配中，千问 Image 2.1 最多接收 10 张，3.0 最多接收 3 张。每张图片最多 10 MB，边长为 1–8000 像素，宽高比不超过 10∶1。
3. 选择输出尺寸。默认是 `1024*1024`，也可选 `auto`；可用尺寸取决于模型。参考图会发往配置的服务，请选用可用于本次请求的素材。

## 失败时检查

- **参考图被拒绝**时，检查所选模型的张数限制、文件大小，以及原图能否完整打开。若使用链接，确认该地址可直接下载图片。
- **接口提示鉴权或地域错误**时，核对百炼密钥与 API 地址。北京地域的基础地址为 `https://dashscope.aliyuncs.com/api/v1`。
- **生成超时**时，可在配置中调整 `tools_image_timeout`，默认 600 秒。程序不会自动重试收费请求。若请求已经提交到服务端，本地取消后仍可能产生费用。
