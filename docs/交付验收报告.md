## 交付内容

- 项目名称统一为微信bot，控制面板采用月白与青绿；原角色卡继续由用户配置。五个管理页面保留全部功能，设置覆盖 15 组、90 项。
- 原文本、图片、表情、语音发送、工具、记忆、三种群模式和自主朋友圈功能保留；补齐接收语音及旧 SSE 缺失身份时的原消息核验。
- 私聊使用真实微信 username，群使用真实 `@chatroom`，群消息逐条保留实际成员微信 ID、群 ID 和原消息 ID。昵称、备注或正文不能替代身份；无法唯一核验时拒绝处理并报告原因。
- 合并窗口默认私聊 0.35 秒、群聊 0.7 秒，持续输入最长等待 2 秒；四个会话 worker，同一会话串行、不同会话并行。媒体保留原顺序；持久 outbox 与有界发送队列支持断线恢复。这些是配置与调度变化，未测量付费模型全链路的延迟改善百分比。
- 拟真保持完整答复，按语义拆气泡并保留代码、链接，使用当前会话记忆调整口语；不随机删字、不额外插入等待。作者昵称和群名不会触发生图或收费语音。
- 主窗口发送重新定位并核验目标、标题、编辑器、焦点、草稿与运行代次；同名无法区分即停止。聊天、语音和朋友圈共享桌面锁，不弹出独立聊天窗口。
- 自主朋友圈配图已接入 `image_prompt → tools.generate_image → 图片完整解码/大小/4000 万像素校验 → MomentsSender`。兼容现成图片路径；缺图或生成失败停止发布，取消后不发出旧任务。文件引用覆盖校验、排队和发送，按年龄及数量清理均尊重引用与待发送文件。
- 自动朋友圈提交前持久保存固定意图，跨进程锁保护提交和人工核对。提交结果不确定、进程中断或历史记录失败会阻止后续模型、生图与发表；面板各页提示待核对，关闭自动朋友圈仍可处理。核对绑定原编号、原历史路径，二次确认后保存，不立即重发。
- 增加定时浏览朋友圈、模型自决策点赞、评论和回复评论，面板可设置频率、互动额度并查看运行与待核对状态。按真实帖子 ID、作者 ID、评论 ID 和评论发送者 ID 处理，同名不会合并；暂停、停止、配置变更和 UIA 恢复失败取消旧代次，手动运行与定时运行共用重入保护。新互动结果的实机边界见下文。
- 微信仅绘制在输入区、未暴露为 UIA 文本的回复提示，可由本机 Windows 中文 OCR 补读。OCR 不生成身份：仍核验真实帖子、评论和发送者 ID、完整原生列表、唯一提示、当前 UIA Runtime ID/几何/焦点，以及同次操作内不超过 30 秒的有效证据；输入框定位、写入、发送和原生回执检查保留 UIA 与身份约束。

## 朋友圈原生身份接口验收

新增三个受原 HTTP 鉴权保护的只读 GET 接口：`/api/v1/sns-identity-timeline` 保留原生记录，`/api/v1/sns-identity-schema` 返回固定白名单表列元信息，`/api/v1/sns-identity-details` 按最多 20 个真实帖子 ID 读取当前账号 `SnsTimeLine` 固定列并交叉核验身份。客户端不能传 SQL、表名或路径；接口复用账号范围及 epoch 检查、共享单飞和响应期限。原生 timeline 缓存评论缺少发送者 ID，不能据缓存昵称补齐；真实评论身份由完整 `LocalExtraInfo` 的原始发送者字段和评论 ID 取得。

在 `0040` 新评论实测前的独立只读接口样本中，得到 20 个帖子、13 条带真实发送者 ID 的评论及 32 个点赞身份，20 个帖子 ID/作者与数据库/XML 对应一致。既有已发测试评论与自用测试联系人的回复目标各找到一次，分别与当前账号和唯一自用测试联系人 ID 精确匹配，且位于自己的帖子。原生本地记录的删除与本地新增状态均为 0；这是当前可读数据库的状态证据，不能宣称腾讯服务器确认或对方已收到。

删除对象不参与发送确认；本地待发、未知或缺失状态不能作为已发结果；缺少原生评论/点赞列表不能当作明确空列表。上述接口样本未遇到已删除或本地待发对象，也没有非零 64 位评论 ID，相关拒绝逻辑、64 位 ID 与 32→64 回复引用、冲突处理仅由模拟验证覆盖。未鉴权、额外 SQL 参数和 POST 分别返回 401、400、405。每次确认都重新读取，缓存尚未落盘的互动不可保证立即可见。

验证器的原始 ASAR 与准备目录必须通过明确参数或环境变量指定，Python 准备器安全测试的原源码目录必须提供 `WEFLOW_SOURCE_DIR`；交付不依赖本机私有 ASAR 或临时准备目录。私有响应仅保留在本机项目外目录，不进入源码或 ZIP。

## 交付与剩余边界

源交付排除真实配置、账号数据、记忆、outbox、日志、依赖缓存和个人角色资源，保留 MIT 与原版权说明。原始 ZIP SHA256 仍为 `4f523a3f3e0190032994847afd43879063d347703085635cad2a38ad211b043a`，没有覆盖。

传输重试采用有限去重与至少一次恢复思路，不能保证跨重启永久去重或端到端 exactly-once。标准 OneBot 不支持完整取消上游模型链；无 reply 关联、经新连接返回的旧答案无法可靠识别。UIA 接受表示本地界面接受，不等于远端送达；结果不确定或部分已发时禁止整体盲重试。已有草稿、焦点变化、无法读取附件预览或恢复失败会明确停止并在面板提示。
