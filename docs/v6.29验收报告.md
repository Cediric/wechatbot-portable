# 微信bot v6.29 验收记录

## 图文通告

本机使用自用配置和四张角色参考图，走通告使用的正式生图函数。主模型编写图像提示，千问接受一次生图请求并返回 HTTP 200。下载后完整解码为 1024 × 1024 PNG，耗时 35.59 秒。原始参考文件保持原尺寸，四张参考图的 Base64 上传量由 8,816,872 减至 4,740,616 字节。

隔离测试走实际面板脚本及发布后端，覆盖请求被拒绝、自动发表关闭时手动接单、创作、生图、微信提交、成功回执和配图失败。生图失败时允许重试；同一账号已有成功记录时不重复发表。微信已接收提交但结果未知时保留待核对的记录。

## 语音与角色

提供的服务器日志中有两次语音合成成功，右 Alt 按下后均未观察到微信录音状态。针对已采集的微信工具栏结构，分别测试了深层嵌套、按钮更名、提前取消和会话变化。带语音的回复不会再以文字重发同一段语音稿。本次由 Esc 停止了本机微信的桌面操作，未在服务器实发或测量新版语音条的首尾留白。

用含英文、表情、空格、非白名单标点及长句的内容核对了流式聊天、非流式聊天、语音稿、朋友圈和主动分享。旧版使用字符规则的自用配置仍保留对发送来源的校验。银月的风格要求可在「全部设置 → 机器人 → 角色卡」调整。

## 服务器日志与实机范围

服务器日志显示 WeFlow 已推送聊天消息，朋友圈定时检查在所录时段因休息时段或私聊优先跳过。旧日志未记录手动通告的受理状态。新版可从通告卡查看手动任务进度；扩展接口结果另见「收集只读诊断」。

本版未向真实朋友圈发布新通告。最近一次本机带图发表、浏览、点赞、评论和定向回评的实测见 [v6.28 验收记录](v6.28验收报告.md)。
