- 图片已有一次界面发送确认，语音已有两次界面发送确认；不能把这份日志描述为图片和语音全部发送失败。
- 群消息进入判断并被持久化后，OneBot 资料查询报“未知用户 ID”。代码与包内 AstrBot 适配器核对表明：群事件的机器人提及需要查询自身群资料，桥接原先没有提供；群成员资料缺少 card 字段又会触发私人资料后备，而群成员使用的会话内编号不能从私人联系人表中查到。

## 修复

- OneBot 群资料查询支持已知群中的机器人自身、群成员备注和原编号；陌生人查询可以解析已登记的同一个群成员编号。成员查询仍核对群原生 ID，群发送仍按群原生 ID 路由，不按昵称改发私聊。
- 明确请求图片时，程序绑定本轮图片意图，不自动补发无关语音；明确同时索要图片与语音仍可使用两者。自然语音请求支持句首“你”，引用、转述、否定不会成为明确语音授权；明确私聊语音请求不会被结束语判断吞掉。
- 图片发送期间取消的旧轮次不再继续生成旧主模型回复。原有请求编号、代次与逐段去重仍保留。
- 图片获取与发送分别计时；语音合成、排队和发送分别记录，固定日志不输出新增聊天正文、密钥或媒体路径。本地队列接受与实际 WebSocket 转交明确区分。
- UIA 在单次操作内缓存标题候选，仍实时读取标题、微信 ID、几何与窗口父链。包含三百条历史节点的离线计数验证中，缓存建立后连续十次身份核验对历史节点属性读取降为零；这不是目标机秒数测量。
- 语音优先检查同进程录音弹窗，播放和录音端点各枚举一次；设备准备与录音观察期间检查取消，释放 Alt 或鼠标并恢复已改设备。没有缩短原观察超时。
- 便携完整启动在原一百八十秒总期限内等待已核验桥接的实际 OneBot 连接；仅面板先打开不报告成功。生命周期帧发送成功且代次仍有效才设置就绪，握手失败和实际转交失败不记录成功。
