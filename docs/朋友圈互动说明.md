# 朋友圈互动

机器人可以给好友的动态点赞、发表评论，也可以回复自己动态下的评论，以及别人在其他动态下对它的直接回复。维护者已在实际使用中确认点赞、评论和定向回评均正常。[v7.0.0 验收记录](v7.0.0验收报告.md)

## 开启互动

1. 用同一账号登录微信和 WeFlow，保持微信主窗口可用。在「全部设置 → 机器人」核对「机器人当前账号微信 ID」。
2. 在「模型工作室」配置「主模型」和「拟真与朋友圈决策模型」。决策模型逐条选择点赞、评论、回评或跳过，主模型负责写评论和回评。两个模型都要填好 API 地址、模型名称和服务所需的密钥。
3. 打开「朋友圈轮询」，勾选「启用自动浏览与互动」。要限定对象，在「允许互动的真实微信 ID」里填写联系人 ID，多个 ID 用逗号或换行分隔。留空时面向全部可见联系人。每类动作可以单独设定每日上限，填 0 即关闭该类动作。
4. 点击「保存设置」，确认机器人已启动。到「会话工作台 → 朋友圈互动」查看下次浏览时间，或点「立即浏览一次」。如果还希望机器人主动发表自己的朋友圈，另行配置「AI 自主朋友圈」。两个开关默认均关闭。

## 什么时候会互动

| 动作 | 默认节奏 |
| --- | --- |
| 给好友动态点赞、评论 | 每 240 分钟主动浏览一次。首次启用会等满一个周期，之后重启沿用该账号已保存的下次浏览时间。 |
| 回复新评论 | 每 5 秒检查一次评论记录。发现可核验且尚未回复的评论后，模型决定是否回复。 |

定时互动受活跃时段、额度和冷却时间约束。私聊优先，默认等私聊空闲 60 秒再处理朋友圈。「立即浏览一次」可跳过定时等待，仍遵守私聊优先、额度和提交核验。想知道这一轮为什么没有动作，可在工作台看最近结果和阻塞原因。

## 出现「互动待核对」

如果点击后无法确认结果，系统会暂停后续互动。在微信里打开对应动态，核对自己的点赞状态或评论文字。定向回评还需核对原评论和回复对象。然后回到「会话工作台 → 朋友圈互动」，按实际情况选「已在微信确认完成」或「确认未完成」。确认后恢复正常调度，不会立即重发这次操作。
