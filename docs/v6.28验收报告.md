# 微信bot v6.28 验收记录

## 本机微信

实测环境为 Windows 本机、微信 4.1.15.56、WeFlow 6.3.2。使用银月账号和同一条带图测试动态核对微信界面和 WeFlow 数据。发布使用正式朋友圈发送器。Windows 原生“选择文件”对话框的文件名输入框嵌在两层组合框中，选择器现在能找到该输入框。发布后按真实作者、正文和新动态编号回读，确认动态包含图片。

刷新后读到六条动态。在测试动态上点赞后重新打开操作菜单，微信显示“取消赞”。WeFlow 也回读到了当前账号的点赞记录。

实机发现微信保留了过时的“20分钟前”标签，导致原来的两分钟误差判断跳过正确动态。修复后，对同一条动态提交“评论功能测试”，在原生明细中按发表者和正文读到了新的评论编号。

账号核验现在可直接打开主导航里的本人资料卡。两次实测中，此步骤由回到封面时的 15.92 秒降至 3.31 秒。这是账号核验一项的耗时。

在同一条动态的两位留言者中，按真实微信 ID 选中烟尘倦客的“回复测试，收到请回复”。微信提交“回复功能测试”后，WeFlow 读到一条新的机器人评论，正文一致，引用编号等于原留言的评论编号。此次真实微信验收覆盖带图发表、浏览、点赞、普通评论和定向回评。

## 账号、媒体和退出

本机原版 WeFlow 的联系人接口包含真实微信 ID 和微信号，已用它纠正误存的账号目录后缀。对同一份真实朋友圈图片密文，原版解密器使用完整密钥可解出 1260 × 1494 的 JPEG，使用经浮点舍入的密钥则无法解码。安装精度修复后，原图和本轮新发布的图片都经实际 HTTP 接口返回；连续九张全部可解码。测试动态下的两位评论者也已通过原生详情接口区分。

在隔离目录启动实际面板与监督服务，“停止”后仍可访问面板，“完全退出”后六个宿主和子进程均已退出，面板端口释放，包目录可立即改名。
