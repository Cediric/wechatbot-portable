# 微信bot v6.26 验收报告

## 公开服务实测

- 使用 B 站公开视频 `BV17x411w7KC` 的首个分 P，从前 30 秒抽出三张 1280×720 的 JPEG。将三帧送入自用配置的 DeepSeek Flash 主模型，提问未提供视频标题。模型依次描述出雪地木屋、人物特写与木纹背景。公开热门接口另返回六条视频。抽帧不含音轨，私密、下架及无法取得画面的内容会说明原因。
- 从 QQ 音乐匿名检索周杰伦《晴天》，取得对应歌曲链接。使用移动浏览器标识访问后显示《晴天》的播放页。虚构歌名返回无匹配。微信出口发送可点击的官方链接，歌曲播放和会员权限由 QQ 音乐处理。[本次命中的歌曲](https://y.qq.com/n/ryqq/songDetail/0039MnYb0qxYhV)
- 自用主模型保留 low 思考。另用合成短句验证了 low 和 Top P 0.97 的官方接口调用，得到了非空回答。自用包的 Top P 沿用模型默认值。在 DeepSeek Flash 的思考模式下，实际可调范围是 0.95 至 1.00。[官方参数说明](https://api-docs.deepseek.com/guides/thinking_mode/)

## 消息与主动分享

私聊、群聊从桥接的常规收件入口进入。测试覆盖完整地址、短链、可识别的 B 站小程序、只带标题但可以按消息 ID 回读原文的分享卡。两个同名聊天使用不同微信 ID。批量群消息只看最新一条分享，其余明确标记未观看。只在群聊决定参与后取视频或搜索歌曲。明确点歌一次只走一个带完整链接的文字气泡。

主动分享使用现有主模型、拟真决策器和微信发送队列。默认平均四小时浏览一次，间隔浮动一成。只在活动时段且私聊空闲时运行。主模型看完公开画面后给出自己的感受与分享语，决策器根据近期会话及兴趣线索选择一个或多个合适对象，也能直接跳过。每日最多分享三个不同视频，同一视频发到多个私聊和群只计一个名额，同一收件人只收一次。验证覆盖重启、最后一个名额的多目标投递、让位私聊、禁用后取消和送达未确认的处理。干净包默认关闭主动分享，自用包默认开启。

角色基础爱好可以编辑，近期喜好和厌倦按观看后的自评逐渐变化，热度半衰期十四天。银月的初始爱好选了剑术、街头摄影和古风器乐。普通聊天可读她目前的喜好，聊天对象的兴趣不会写成银月的喜好。使用独立微信账号和角色卡验证了隔离及切换时在途反馈的归属。

匿名实测“街头摄影”和“古风器乐”分别获取六条公开候选。“剑术”检索第一页返回 HTTP 412，第二页可读取。在实际流程中，单次搜索受限会改用公开热门。没有合适收件人或当天三个视频名额用完时，角色仍能自己看视频并更新兴趣。

上述私聊和群聊送达覆盖采用真实业务入口和模拟微信发送器。公开网站和主模型已联网实测，本版没有向真实群或联系人投递测试链接。此前普通微信文字、图片及语音的 UIA 实发结果见[上一版验收](v6.25验收报告.md)。

## 长期记忆和上下文

按合成聊天和 SQLite 数据验证了遗忘曲线。自动抽取的事实默认每三十天召回权重减半，再次获得同一人、同一事实的新证据后更新。查询、消息重放及批次里的无关新话不会刷新旧事实的年龄。手工和明确要求记住的事实保留。关闭曲线可恢复原有相关度排序，数据库中的记忆一直可在面板查看。

自用包允许按真实发言人跨会话回忆。聊天上下文独立压缩，当前上限 256,000 token，估算输入达到可用输入预算的 82% 附近时整理早期对话。

语音回归发现录音标签的控件类名在同一步被取了两次，其中一次只用于写日志。本版复用第一次的读数，右 Alt 手势、录音窗口识别和发送条件保持原有流程。该改动通过合成微信窗口测试。
