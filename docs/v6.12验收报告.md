# 微信bot v6.12 验收记录

本轮针对服务器六点一零日志中的朋友圈提交身份不一致、间歇性刷新失败和面板结果混淆进行修改。日志证明两次读取二十条动态后处理一条，均在互动菜单打开前因身份不一致停止；另一次刷新按钮确认失败。日志没有记录两边的实际 ID，不能据此确认服务器一定属于目录后缀问题，也不能用读取成功代替实际互动成功。

WeFlow 所选账号的 `myWxid` 可指账号目录名，目录名可能包含四位后缀。一键启动曾将它原样写入机器人 ID。现在只在所选本机账号目录与连接配对一致、且新鲜原生身份快照能唯一证明对应关系时转换；原生完整 ID 优先，其他手填账号不覆盖，无法证明时保留配置并提示核对。微信实际身份卡核验继续使用原生 ID，不能按昵称或角色主人编号放行。

朋友圈刷新兼容已核验主窗口由 UIA 暴露为 PaneControl 的情况，仍要求原主窗口 HWND、PID、微信类和真实父链。刷新按钮使用首次冻结的原生标识，在点击前重新核验原主窗口归属、前台、按钮可见启用状态和取消状态；控件重建或工具栏被移到同进程其它弹窗时停止。

机器人当前账号 ID 在自己的面板中直接显示，便于核对；API 密钥、连接令牌和登录密码继续隐藏。面板区分最新检查结果与最近执行错误。回评轮询没有新候选时，不再把前一次刷新或互动失败隐藏成整个链路已恢复；错误提示不改变互动的去重、时段、配额、重试和账号校验。状态与日志在释放执行锁前归档，避免旧失败覆盖后续已核验的成功。原最近手动请求记录仍独立显示。

本轮测试记录：UIA、朋友圈发送与相关窗口核验四百零八项；朋友圈交互、时段及状态九十一项；账号同步二十二项与令牌十二项；面板接口三十五项，均通过。面板行为脚本通过。不同代理只读交叉复核，并独立重跑账号合成测试；重复执行不重复计入测试数量。

本轮仅使用合成窗口、合成身份快照和本包离线测试。没有向真实微信或朋友圈提交内容，也没有启动本机桥接、AstrBot 或控制面板。服务器实机验收尚需在更新后确认，不宣称所有微信版本已通过。

自用包沿用最近授权的设置、人设、模型、音色和参考图。新包不包含当前运行数据或本机连接字段，干净包不包含自用密钥和角色素材。完整便携依赖继续内置。
