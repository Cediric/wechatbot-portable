# 微信bot v6.10 验收记录

本次修复便携启动器读取 WeFlow 加密 HTTP 令牌时，把存储密文当作请求凭据的问题。Windows 当前用户下读取 WeFlow 本机 `Local State` 密钥，验证密文后仅在内存传给请求与桥接；不覆盖 WeFlow 已有密文。不具备解密依赖的启动解释器调用包内已经准备好的桥接环境，凭据仅在捕获的管道中传递。

明文旧配置仍可使用。空令牌、未识别封装、解密失败或身份配对不符均不作为有效 HTTP 凭据；失败原因不包含令牌或原生异常数据。

实现与独立代理交叉复核完成，56 项针对令牌、账号同步、便携启动及 ASAR 的合成回归通过，覆盖加密验证、固定环境后备解密、保密输出、账号匹配与保留原配置。
