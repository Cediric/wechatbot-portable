# 微信bot v6.27 验收报告

桌面 v6.26 实例中有三次主模型已经生成首句，桥接只收到空结束帧。本版测试了常用异体标点、夹带的装饰表情、禁用字母和一个流中的多句话。可修正的文字会送出，跳过无效句后可继续发送，整轮没有合法正文时记录原因。

同一群的输入控件在 Qt 控件树中挪位时，按已核验的控件身份继续发送。切换到其他会话时仍选择真实目标。群聊与私聊在模拟微信窗口进行回归。生图仍按同一聊天的消息顺序执行，后续同会话消息可能等待。

已用官方 DeepSeek 接口检索一条公开测试问题并取得网页结果。已显式配置 Tavily 的实例继续优先使用该服务。自用配置中的现有模型和角色卡继续沿用。

控制面板的首次上线按钮直接启动图文创作。图片生成、正文及图片提交、账户切换、重复点击、进程重启和结果核对采用隔离账号数据测试。发布调用使用模拟微信发送器，微信中的真实首次发表由用户点击。该记录保存在桥接的 data 目录，升级迁移时应一并保留。

一次真实接口预演从同一个按钮对应的后端入口开始，使用虚构角色、合成参考图和隔离的发表记录。DeepSeek Flash 撰写文案与整理画面要求分别耗时 2.42 秒和 2.38 秒，千问 qwen-image-2.1-pro 出图接口耗时 11.95 秒。模拟微信发送器收到正文和可解码的 1024 × 1024 图片，从点击到本地记录完成共 23.64 秒。

本机通过开始菜单快捷方式找到了 D 盘安装的 WeFlow。启动器和朋友圈读取用例覆盖托盘未退出、非默认安装路径和提供评论者微信 ID 的接口缺失。运行中的 WeFlow 保持原状，本版未在该实例执行安装并回评。
