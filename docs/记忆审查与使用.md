# 共享记忆

机器人可以从聊天原话中保存称呼、偏好等长期事实，并按真实微信 ID 归到发言人名下。比如群里有人说“以后叫我小陈”，之后改了群昵称，这条记录仍归同一个人。记忆保存在本机 SQLite 数据库中，自动抽取使用你配置的模型。

## 开启和选择范围

1. 打开「模型工作室 → 共享记忆」，确认「启用共享记忆」，填写记忆模型的 API 地址、模型名和所需密钥。
2. 在「全部设置 → 记忆与维护」找到「记忆检索范围」。默认按会话检索。在私聊里保存的称呼若也希望在群里使用，可以选择「同一微信用户跨会话」，然后点击「保存设置」。

跨会话只召回同一人可共享的日常事实，例如称呼和口味。私下约定、涉及隐私的记录和聊天原文留在原会话。临时问候通常不会形成长期记忆，因此换到另一个群提问时，机器人无法靠这项功能复述刚才的整段私聊。

## 查看、纠正和遗忘

- 在侧栏「共享记忆」按内容或来源搜索。展开「查看原文证据」可以对照当事人的原话、发言人和会话。检索按关键词匹配，找不到时可试原话中的词。
- 记错了一条，可在该条记录点「删除」。当事人也可以在聊天里明确更正，例如“以后叫我小林”，新的原话可用来更新同一人的称呼。
- 在「模型工作室 → 共享记忆」可调「启用遗忘曲线」和「自动记忆半衰期（天）」。默认半衰期为 30 天，越久没有新证据，自动抽取的事实越不容易被带入回复。手工添加和明确要求记住的事实保留。
- 「清空全部记忆」会永久删除所有记忆和本地聊天日志，包括当前搜索没有显示的内容。只需清理某条时，使用该条记录的「删除」。
