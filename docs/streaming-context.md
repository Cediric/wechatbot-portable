# 流式回复与上下文

在「模型工作室 → 主模型」勾选「边生成边回复」，然后点击「保存设置」。模型写完一句话，机器人就可以把它作为一个微信气泡发出。关闭后，机器人会等整段回复生成完再发送。设置从下一次请求起生效。

句子较长或一直没有句末标点时，第一个气泡可能要等到这一段写完。纯语音回复也会等台词完整后再合成发送。若想了解时间花在哪里，可在「会话工作台 → 回复耗时与运行状态」查看首段生成、排队与微信发送的耗时。

## 对话很长时

以下设置都在「模型工作室 → 主模型」。先按服务商所用模型的实际容量填写上下文和输出上限，再调整摘要方式。

| 设置 | 作用 |
| --- | --- |
| 上下文上限（估算 token） | 角色卡、提示词、聊天历史、当前输入、媒体、工具及输出预留共用这份预算。 |
| 最大输出token | 为本轮生成预留空间。设得越大，能留给历史的空间越少。 |
| 自动摘要旧对话 | 较早的对话压缩为同一会话内的摘要，近期对话保留原文。关闭摘要或摘要失败时，超出预算的旧轮次会被裁去。 |
| 摘要触发占比 | 控制提前多少开始压缩。例如 0.82 表示估算输入用到预算约 82% 时触发。 |
| 保留近期原文占比 | 调高可保留更多近期原话。如果希望摘要着重保留未完成事项，可在「摘要补充要求」填写。 |

同一会话的摘要用来接续长对话。希望机器人在以后的聊天里记得某个人的称呼、喜好，或想查看某条事实的来源，可在共享记忆中设置。[共享记忆使用说明](记忆审查与使用.md)
