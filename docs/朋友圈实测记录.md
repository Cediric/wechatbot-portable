测试图由内置 imagegen 生成，内容为窗边白猫与茶杯，带“微信bot 测试图”标识。PNG 1254×1254，2,373,449 字节，完整解码通过，SHA256 为 `2579beb9682b08ad9a45958c8888ba53fb8dd1521b66aa841ca512ea9aacfda6`。原图与私有运行记录保留在工作目录，不打进源交付包。

实测发现并修复三处真实 provider 差异：Python 控件包装对象每次遍历可能重建，改用非空真实 RuntimeId 比较；朋友圈编辑器可读写但焦点接口仅报告外层窗口，改用定向 ValuePattern 并准确读回；Qt 文字菜单激活后会消失，改为核验主窗口/菜单/项身份后不激活点击。图片的添加按钮与匿名图标不能作为已附图证明，实际网格与唯一图片项在提交前再次核验。

用户已明确授权精确构建的单字节临时恢复方式。每次项目测试使用会话内设置、175 秒取消上限和 `finally` 关闭还原；两次成功调用均报告 `restoration.ok=true`。最后独立只读检查相同进程/版本/DLL SHA，允许修改和只读核验的两个状态值均为 `0`。未修改微信程序文件或全局系统设置。

正式自动流程为决策模型的 `image_prompt → tools.generate_image → 完整图像校验/引用保护 → MomentsSender`，已有图片路径优先。项目当前未配置 DashScope 生图密钥与朋友圈决策模型密钥，真实付费 API 调用没有执行；其接口接线、错误处理和防重复发表以模拟回归验证。本次成功证明真实 UIA 选图、正文、发表与核对流程可用，不把内置工具生成的图片当作项目付费 API 已验收。

提交后的结果不确定或进程中断会保留固定的 `data/moments_pending.json`，阻止后续决策、生图和发表；需要在微信核对后从面板解除，不能自动盲重试。完整设置、待核对操作和验收范围见 [使用说明](../README.md)、[UIA 说明](UIA验收说明.md)及 [交付验收报告](交付验收报告.md)。

## 2026-10-12：浏览与互动

项目公开方法 `MomentsSocialSender.refresh_feed` 已实机刷新列表；点赞测试在自己的纯文字测试动态完成，提交后重新打开同一菜单核验为已点赞，没有点击取消赞。

第一次评论标识为 `微信bot 互动实测｜评论｜20261012-0005`，微信界面实际出现一次。该次公开调用因评论编辑器重建返回结果不确定；独立截图确认后没有重复发送这条评论。

补齐确认逻辑后，在自己的带图测试动态发表 `微信bot 评论确认实测｜20261012-0040`。公开方法返回 `accepted_by_ui`、`submit_attempted=true`、`outcome_uncertain=false`、`acknowledgement=native_comment_record`；核验提交前不存在、提交后新增的真实评论 ID、自己的微信 ID、完整正文及原动态身份。随后独立桌面截图也确认该评论出现。测试标识用于区分内容，实际完成于约 01:00。

这轮实测在最大化微信主窗口中完成。带图动态起初位于窗口下方，程序在提交前停止；修复后按实时 UIA 条目范围和命中控件核验滚轮导航，再重新读取完整目标。当前微信的朋友圈列表没有提供 `ScrollPattern`；后备导航仍要求同一主窗口、前台、列表与目标控件 ID，移动前后重新检查，不能对任意屏幕位置滚动。几次定位失败均未提交，没有重复评论。

定向回复于约 02:09 通过公开方法实测：回复自用测试联系人在带图动态下的“回复测试”，发送内容为 `微信bot 定向回复实测｜已核验微信ID｜20261012-0035`。标识中的 0035 用于区分内容，不是实际发送时间。公开方法返回 `accepted_by_ui`、`submit_attempted=true`、`outcome_uncertain=false`、`acknowledgement=native_comment_record`。提交前不存在该正文，提交后出现唯一新真实评论 ID；自己的作者 ID、完整正文、`ref_comment_id` 和 `ref_author_id` 均与原动态、原评论和原评论者准确对应。独立桌面截图确认出现一次“自己 回复 自用测试联系人”的完整回复，没有重发。

本机回复编辑器的 UIA/MSAA 均未暴露画面上的“回复某人”提示。Windows 中文 OCR 在已绑定的空编辑器范围内读到完整正确提示；定位、输入、正文准确读回与发送仍由 UIA 执行，身份及提交回执由原生记录核验。Qt 命中测试在编辑器范围返回所属虚拟评论区；只接受编辑器父链中的原评论区及一致的进程、控件身份、焦点和边界。任何可读 UIA 提示冲突、控件变化或无法唯一对应真实原评论 ID 的情况都会停止。早期失败调用均未写入或提交；本次仅发送成功回复一次。

最终调用使用独立测试父进程持有临时恢复租期，子测试结束后确认还原；随后只读核验原进程、构建身份与两个状态值均为 `0`。WeFlow 验收期间临时启用的 HTTP API 和密钥已恢复到原来的关闭、空密钥状态，托盘关闭行为及其他设置保留；已安装的接口扩展与原包备份保留。

原生数据库记录和界面证据属于本机接受证明；`delivery_verified=false`，不代表所有联系人送达。真实模型自主决策与付费生图调用仍需配置密钥后另行验收。
