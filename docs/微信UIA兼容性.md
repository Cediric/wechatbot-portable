# 微信 UIA 的版本兼容

正常路径先读取实际主窗口的 UIA 控件，按控件类型、完整标识片段、父子关系及相对窗口位置识别搜索、聊天标题、编辑器和朋友圈。控件完整时，不要求微信版本出现在恢复名单中；窗口最大化不会改变这条原则。模拟回归覆盖未列出的 Qt 主窗口版本完成聊天及内嵌朋友圈操作，全程不调用恢复开关，也不打开独立聊天窗口。

只有主窗口不暴露必要控件时，才使用已复核构建的临时恢复。适配资料与操作流程分离，每个资料分别绑定文件版本、完整 DLL SHA256、AMD64 架构、映像大小及复核地址；按该主窗口对应进程实际加载的模块选择，不能根据安装目录、下载文件名或第一个同名进程猜测。事务选择的地址也用于还原，微信升级、进程重启或另一个资料不会把旧事务改到新地址。

未知版本仍可使用完整的正常 UIA。需要恢复但找不到精确资料时，只报告安全的构建元数据，拒绝读取或试写候选状态地址。离线指令匹配用于研究，不能自动进入运行名单；用户配置或网络返回的地址也不能授权内存修改。每次更新都要复核地址，而无需重写聊天、朋友圈和还原流程。

四点一十五点五零的主 gate、Qt 类别 helper、两组日志函数、getter 与 setter 共六个完整函数，在仅排除反汇编明确标出的跨构建 PC 相对位移后逐字节对应；所有函数内分支一致。getter、setter 和主 gate 都指向同一个数据字节。第二个候选行为发生变化，未纳入此构建的读取或写入资料。

五零构建的 DLL SHA256 为 `0cf6379405432385a1c442766443450f26a7689f45e53c1b4ad2822061f3113b`，映像大小 `204587008`，唯一恢复地址为 `0x0B36B9D8`。固定安装器 SHA256 为 `d7b4580e2a83a127171b5208492549264e63cedd8bf992edf01579682dd7cc17`，对应[微软 winget 原始分发清单](https://github.com/microsoft/winget-pkgs/blob/master/manifests/t/Tencent/WeChat/Universal/4.1.15.50/Tencent.WeChat.Universal.installer.yaml)。本次仅下载、验签和解包，没有运行安装器或升级微信。官方不带补丁版本号的下载地址会被后续构建替换，因此文件名相同不代表字节相同。

十三构建的 DLL SHA256 为 `10f8e995453e2da46d4f2b5080cd6da1f13cc5147746adc119ceae38cb039de5`，映像大小 `202039296`，唯一恢复地址为 `0x0B135C38`。只读主窗口检测确认本机当前对应此构建，未根据其他同名后台进程猜版本。

本机十五点十三的短时准备实测在同一主窗口中从4个节点恢复到93个节点，搜索、聊天标题及可读编辑器的可用判定通过；准备、读取及立即还原共1.688秒。临时事务关闭报告 `ok=true/status=restored/wrote=true`；独立代理随后核验相同模块及页面，仅用只读句柄读取一次主开关，确认已经还原为0，未再写入。本次未提交聊天或朋友圈；这项结果也不能替代目标机五零构建的运行验收。资料中的 `static_equivalence` 记录地址纳入的静态依据，实际控件和发送仍逐次核验。

恢复保留原有进程创建时间、主窗口句柄、模块身份、完整哈希、不可执行可写映像页、原值、单字节写入及读回检查。170秒租期、条件还原、失败保留句柄与诊断保持有效。恢复完成后仍要重新取得同一个主窗口并确认 UIA 控件；不放宽真实身份、草稿、焦点和提交结果核验。

## 排查更新后的微信

面板“发送与设备”显示实际构建、可用的已复核资料和匹配结果，复制诊断仅复制安全元数据。双击根目录“收集只读诊断.bat”可生成 `portable/runtime/只读诊断报告.json`，不切换会话、不读取状态字节、不启动服务；报告也不包含账号、聊天、密码或用户目录。删除旧日志后仍可收集当前构建与监听状态。

UIA 不可用与 AstrBot 服务启动失败分别报告。端口有监听不等于本包服务启动成功，服务归属还要独立核验。目标机完整日志已删除时，不能根据版本差异反推 AstrBot 退出原因；需要下次启动产生的脱敏错误。
