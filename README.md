# 微信bot

给 Windows 桌面微信接上你选的 AI 模型。它可以按你设定的语气回复私聊、在群里被 @ 时接话，也可以发表朋友圈、给好友的动态点赞、评论，或在评论区回复对方。

**[下载 Windows 便携版 · v7.0.0](https://github.com/Cediric/wechatbot-portable/releases/download/v7.0.0/wechatbot-v7.0.0-portable.zip)** · [所有版本](https://github.com/Cediric/wechatbot-portable/releases) · [更新记录](CHANGES.md)

## 先跑通一条私聊

1. 在 **Windows 10/11 64 位**上登录桌面微信，在 WeFlow 选中同一账号，确认数据库连接成功。在 WeFlow 的「设置 → API 服务」开启 HTTP 服务和「主动推送」。已适配的 WeFlow 6.3.2 需要生成连接令牌。
2. 将上方的 `wechatbot-v7.0.0-portable.zip` **完整解压**到可写目录，预留至少 4 GB 空间。便携包包含 Python 和运行依赖，GitHub 的「Source code」压缩包仅供查看源码。
3. 双击根目录的 **一键启动.bat**。在控制面板的「模型工作室 → 主模型」填写支持视觉输入的模型地址、名称和 API Key，保存设置。
4. 用另一个微信账号给机器人发一条私聊。看到回复回到同一个聊天窗口，就跑通了从 WeFlow 收信、AstrBot 调用模型到微信发信的整条链路。

## 可以怎样用

| 场景 | 用法 |
| --- | --- |
| 私聊与群聊 | 在角色卡里写称呼、语气和回复习惯。长回复可以逐句发出。群聊默认仅在被 @ 时回复，也可配置参与规则。 |
| 朋友圈 | 可以发纯文字或带图动态。**点赞、评论和定向回评已由维护者实测通过。** 自动发表与自动互动分别开启，默认均关闭。[朋友圈设置](docs/朋友圈互动说明.md) |
| 长期记忆 | 记住同一人的称呼和偏好，默认按会话隔离。可开启同一微信用户跨会话召回，也可在面板查看和删除记录。[记忆设置](docs/记忆审查与使用.md) |
| 图片、语音与链接 | 可用参考图生成图片、合成语音、根据 B 站视频抽帧接话，或发送 QQ 音乐歌曲链接。生图与语音需配置相应服务，微信语音发送还需虚拟声卡。[生图设置](docs/qwen-image.md) |

## 运行与数据

WeFlow 通过本机接口推送新消息，桥接程序把聊天交给 AstrBot，再通过 Windows 界面自动化（UIA）操作微信主窗口发送回复。运行时请保持微信已登录、桌面可交互。聊天记忆保存在本地；模型、搜索、生图和语音功能会把所需的内容交给配置的服务处理。

自动操作微信存在账号受限风险，建议先用测试账号。反馈问题时请提供脱敏报错，保管好 API Key、面板密码和聊天数据库。[使用说明与免责](DISCLAIMER.md)
