# 微信bot v6.32 · 便携版

Windows 微信助手。WeFlow 接收真实微信消息，桥接转交 AstrBot，模型回答后通过微信主窗口 UIA 发送。项目名是 **微信bot**，昵称和角色卡自行配置。

服务器上的维护 Agent 从 [服务器维修交接](服务器维修交接.md) 开始。文档按症状列出日志、维修入口和验证方法。[本版更新](CHANGES.md)

## 双击启动

1. 解压整个 ZIP 到可写目录，建议至少预留 4GB 空间；不要直接在压缩包内运行。
2. Windows 10/11 **64位**上打开并登录微信、WeFlow。
3. 双击 **一键启动.bat**：检测/安装包内独立 Python、桥接及 AstrBot 环境，初始化配置、启动服务并打开面板。不要求预装 Python、Git 或 uv；后续复用已有环境和数据。
4. 干净包首次在面板填写模型地址、名称和 API Key；自用包保留已选择的人设和模型配置。核对 WeFlow、真实 wxid、UIA 与音频设备。模型账号与可用额度须自行准备，不会自动购买 API 服务；包含私人密钥的自用包仅供本人使用。

详细运行环境、组件校验、WeFlow 精确版本适配与驱动说明见 [便携启动说明](portable/README.md)。驱动可能需要系统管理员确认，不绕过 UAC。未知微信/WeFlow 构建明确提示未验证能力。桥接默认 `http://127.0.0.1:8766`，AstrBot 默认 `http://127.0.0.1:6185`；首次随机登录密码在 `portable/runtime/astrbot-instance/dashboard-login.txt`，不要分享运行后的整个目录。

启动失败的具体阶段及脱敏后异常保存在 `portable/runtime/startup-error.txt`；外层启动脚本保留这份真实原因，避免只显示退出码。排查时提供错误文字即可，勿分享配置及登录密码文件。

运行后，桥接监督器持续观察线程和桌面任务进度。操作长时间没有进展时先取消并还原临时状态，确认旧进程退出后恢复；未确认的消息不自动补发。突然崩溃时恢复面板并保持暂停，核对微信当前状态后可点“继续”。会话工作台的“回复耗时与运行状态”显示当前任务、分阶段耗时和语音缓存统计。详见 [本版运行恢复说明](docs/v6.20验收报告.md)。

服务启动失败会区分桥接与AstrBot，保留实际退出码、等待上限及本轮脱敏错误。首次便携服务启动最多等待180秒；界面提前就绪便立即打开，超时不会结束尚在运行的服务。旧日志删除后，也可以双击 **收集只读诊断.bat**，生成模块构建、监听状态及日志文件是否存在的报告；不读取聊天或密码，不切换微信会话。

微信正常UIA按控件结构识别，不以固定版本号为前提；缺少控件时才按实际模块选择已复核的临时恢复资料。新构建的离线核验与实机效果分别说明，未知构建不会试写旧地址。详见[微信UIA兼容性](docs/微信UIA兼容性.md)。

## 模型与媒体

「朋友圈轮询 → 首次上线通告」可以立即发表一条带图的朋友圈。主模型结合人设写公开文案和配图要求，生图成功后一起交给微信。自动发表开关可保持关闭。发表结果不确定时，在工作台核对那条朋友圈即可。同一个账号的成功标记随本包 data 目录保存。

使用官方 DeepSeek 主模型时，打开「联网与生图」即可用同一密钥按需搜索网页。如果填写了 Tavily 密钥，网页搜索优先使用 Tavily。[DeepSeek 网页搜索接口](https://api-docs.deepseek.com/zh-cn/guides/search/)

在私聊或群聊发 B 站链接或分享卡片，主模型可以结合公开取得的视频画面接话。它看到的是顺序抽帧。点歌可以发“点歌 周杰伦的《晴天》”，微信里会收到可打开的 QQ 音乐歌曲链接。

工作台的“视频和点歌”可以调整视频阅读、点歌、角色基础爱好和主动分享。默认在朋友圈的活动时段内约四小时浏览一次。主模型看完后可形成新爱好，在后续聊天与选片时体现。“共享记忆”页可查看角色当前的兴趣。

拟真模型可以只看，也可以把视频分享给最近七天交流过的一个或多个私聊或群。每天最多分享三个不同视频，同一视频发给几个聊天都只占一个名额。

在“全部设置 → 共享记忆”可调遗忘曲线和半衰期。默认三十天后，自动抽取的事实召回权重减半，新的聊天证据可刷新时间。手工添加和明确要求记住的事实保留。主模型的上下文压缩另行设置。

在「记忆检索范围」选择「同一微信用户跨会话」后，银月可以在另一个群或私聊想起同一人的称呼和普通喜好。只有被判定为本人可公开的日常事实才会跨会话，其余一律留在原会话。没有相同关键词时，最多带入两条仍清晰的人物事实。私密记忆和原始聊天留在原会话。**跨会话共享的是长期事实，不是短期对话**：刚说过的一句「oi」或一次提问不会被抽成记忆，换到另一个会话后不会被复述。

在“模型工作室 → 主模型”可以调温度和 Top P。DeepSeek Flash 开启思考时可调 Top P（0.95 至 1.00），关闭思考后可调温度。Top P 设为 -1 时沿用服务商默认值。[DeepSeek 参数说明](https://api-docs.deepseek.com/guides/thinking_mode/)

| 用途 | 模型工作室中的角色 | 行为 |
| --- | --- | --- |
| 主模型 | 主模型 | 理解聊天和朋友圈媒体；创作聊天文字、语音台词、朋友圈文案与生图提示词。须视觉模型。 |
| 记忆抽取 | 共享记忆 | 抽取有逐字证据的用户事实，按真实发言者归属。 |
| 群聊判断 | 群消息回复判断 | 判断是否参与、回复方式及工具，可关闭。 |
| 主动发表 | AI 自主朋友圈 | 只决定是否发表及是否配图，正文和画面交给主模型；默认关闭。 |
| 生图提示词 | 主模型 | 根据画面意图与参考图说明创作提示词，再交给生图 API 执行；旧独立提示词模型配置仅保留兼容。 |
| 拟真与朋友圈互动 | 拟真与朋友圈决策 | 只决定是否参与、动作及表达形式；评论和回评由主模型撰写，当前一条执行核验后再下一条。 |

五种用途各自配置地址、密钥、模型、提示词、思考模式、参数格式、预算/强度、上下文预算、输出上限、温度和超时。主模型的多个写作任务各自使用独立请求和明确输出格式，朋友圈正文只进入朋友圈，生图提示词只进入生图接口。选择语音时不再附发相同文字；已经流式发送的文字不会再合成同一段语音。随包 AstrBot 插件把主模型配置用于正常回复管线；后续请求热更新，进行中的请求保留配置快照。没有额外图片描述模型。思考参数须被供应商支持，否则明确报错，不悄悄撤掉设置或重试付费请求；隐藏推理不作正文或记忆。token 为估算，并非供应商精确 tokenizer。部分 OpenAI 推理模型不支持关闭思考。

拟真决策启用时，私聊与朋友圈复用同一模型配置，但使用各自的任务提示词；群聊把拟真方案并入已有群判断请求。只读当前人的相关记录，群聊不会注入成员的私聊。主模型接收相关聊天、朋友圈与拟真决策，在角色设定内创作画面，作品构图不写成真实经历。内置分工约定不受旧版用户提示词覆盖，决策草稿不能作为写作失败时的正文备用。

主模型采用真实 API 流式输出，生成完整短句后逐段发到微信。系统提示、媒体、工具与输出预留共同计入主模型上限（最多500,000 token）；接近预算时自动摘要同会话旧历史并保留近期原文。普通补充消息留在同会话缓冲，等本轮交付结束再处理；明确停止要求仍取消旧轮。已确认片段不因最终全文或重试重复发送。详见 [流式与上下文设置](docs/streaming-context.md)。角色卡直接进入主聊天请求，角色主人只能绑定真实微信 ID，不能凭昵称认主。

生图与参考图页：千问及 Wan 生图模型、尺寸、多参考图和用途说明，使用 DashScope API 地址/Key。默认千问二点一Pro；二点一最多10张参考图，三点零最多3张，Wan按模型为4或9张。角色外貌参考与摄影风格参考按各自用途交给主模型，再由主模型创作最终提示词。随包含默认不选中的通用构图示例，无私人角色人像；可上传及预览。素材仅在生图时发往供应商。声音与克隆页：音色、模型、语速、音调、音量，创建克隆、列表、状态、删除与试听。点击创建才让供应商读取公开HTTPS录音，创建/试听可能计费，不自动上传聊天录音。

视频默认最多4张均匀采样画面，动画表情也有界采样；不包含视频音轨，不代表看过每一瞬间。可选原视频模式，需供应商/AstrBot支持。解析失败明确提示，朋友圈停止该条判断，不用缩略图冒充完整视频。

## 朋友圈、记忆与节奏

朋友圈轮询页控制开关、间隔、每轮数量、每日额度、冷却、活跃时段、真实微信ID范围和提示词。每条独立上下文：主模型查看 → 独立决策 → 主模型撰写需要的评论或回评 → 执行核验 → 下一条。跳过、点赞不额外调用写作。结果不确定持久记录并暂停，须在微信核对后恢复。主动发表/互动均默认关闭。

主动发表默认每150分钟决策，主动点赞与评论默认每240分钟触发。**这个周期按账号保存在数据目录里，重启不会重新计时**；启动日志会写明下次主动互动的具体时间，未到点时只做回评轮询，面板的「立即浏览一次」可以提前执行。新评论单独每5秒检查；无待回复评论时不刷新微信界面。私聊处理完且空闲60秒后才处理朋友圈，新私聊到达则在安全边界让出界面。首次观察建立评论基线，避免启动时批量补回历史评论。

朋友圈需要的是**机器人当前登录账号**的真实微信 ID，不是角色主人或联系人的编号。一键启动在接口核验成功、地址/端口/密钥与本机 WeFlow 配置一致时，从 WeFlow 保存的所选账号填补空值；已有手填编号保留。保存的选择不代表微信当前登录状态，请确认两边使用同一账号。无法同步时，朋友圈卡片提供配置入口并显示具体原因；手动浏览不再把拒绝执行显示成“浏览中”。

某条媒体无法取得或转换时，略过该条，不凭未读图片做决定，继续处理后续独立动态；主模型接口或摘要失败则停止本轮。媒体有失败时，下一轮评论检查至少间隔60秒，避免反复读取同一坏图。面板保留最近媒体错误，历史未提交记录显示具体原因。朋友圈页有实时选中证据时，列表暂不可读先恢复同一主窗口，不再次点入口把页面关闭。

首次启用不会立刻主动发布或批量点赞评论：发布等待完整150分钟，主动浏览等待240分钟；“立即浏览一次”可提前手动浏览。因私聊、活跃时段或暂时读取失败而未执行时，保留到期任务并稍后检查，不再白等一个完整周期。面板显示下次发布检查、最近检查、阻塞原因和手动任务最终结果。

在「全部设置 → 机器人 → 角色卡」里设置回复长短、字母和标点习惯。银月通常每条消息不超过十五字，需要详细说明时可适当展开。非流式回复按完整句和换行分泡。

智能合并默认私聊0.35秒、群聊0.7秒，最长2秒；同会话串行、跨会话并行。首回复最短0.8秒、气泡间隔0.25秒、单条朋友圈互动最短1.2秒，均只补剩余差额，模型已耗时则继续。这用于自然节奏，不保证平台风控结果。

上一轮处理期间收到的新消息，释放后只等待尚未用完的合并时间。模型流读取与微信发送等待重叠，最多缓存4个待发片段；发送保持同一请求的顺序并核验原生身份，失败或取消停止剩余片段并关闭模型流。发送结束使用轻量本次观察，点击只读诊断才进行完整扫描；面板标明观察来源，不用旧快照证明当前发送目标。

收消息核验原微信username/wxid、群`@chatroom`ID、真实成员和原消息ID，昵称/备注/群名只显示与定位。已验收WeFlow扩展支持fresh身份快照，默认3秒检查，真实系统事件触发刷新；仍受微信落盘和接口可读状态限制。

记忆是SQLite持久化+本地关键词检索，默认按会话与实际发言者隔离，不是向量语义记忆。记录带证据/消息ID/来源/更新时间，同人同字段可更新；无归属旧群记忆保留但不注入。助手回复只记聊天日志，不抽为用户事实。详见 [记忆审查](docs/记忆审查与使用.md)。

记忆抽取按单条消息处理，原文默认最多8,000字符、可调至32,000。接近独立模型预算时，本机保留完整原文片段，不新增摘要API调用；证据须逐字来自一个片段，截断后的半句不能写成长期事实。主聊天的会话摘要另行维护，见[流式与上下文设置](docs/streaming-context.md)。

面板有9页，包括工作台、模型、朋友圈轮询、生图与参考图、声音与克隆、全部设置、记忆、发送与设备、日志。设置可跨页编辑后统一保存，凭证会隐藏。修改 `web_port` 或 `memory_db_path` 后须完整重启，更新连接和身份设置会触发重连。[完整字段](docs/配置字段.md)

升级前备份配置、data、身份映射、角色卡、参考图、表情包；不要用示例覆盖用户配置。暂停/停止取消未完成工作，已有提交不能撤回；持久队列采用重试，不承诺上游exactly-once。

新版一键启动会先识别占用当前面板和 OneBot 端口的旧微信bot，核验后依次退出旧桥接和旧 AstrBot，再启动新包；旧数据仍在原目录，不自动覆盖或合并。无法核验的占用会显示端口和进程编号，需先退出对应程序。
