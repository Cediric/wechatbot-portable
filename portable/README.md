# Windows 便携版使用指南

适用于 Windows 10 / 11 64 位。便携包内含 Python、uv、AstrBot、FFmpeg 和运行依赖。微信桌面客户端、WeFlow 和模型服务账号需自行准备。[项目首页](../README.md) · [下载便携包](https://github.com/Cediric/wechatbot-portable/releases/latest)

## 第一次启动

1. 在发布页的 **Assets** 中下载文件名以 `-portable.zip` 结尾的附件。把整个压缩包解压到当前用户可写的目录，建议预留至少 4 GB 空间。GitHub 自动生成的 **Source code** 压缩包缺少运行依赖。
2. 打开并登录微信，在 WeFlow 选中同一账号，确认其数据库连接测试成功。进入 WeFlow 的「设置 → API 服务」，启用本地 API 和「主动推送」。使用已适配的 WeFlow 6.3.2 时，请生成连接令牌。启动器会尝试从当前 Windows 用户的本机配置同步它。
3. 双击解压目录中的 **一键启动.bat**。首次启动会准备本包的独立环境，并检查桥接与 AstrBot 的连接。对于匹配的 WeFlow 6.3.2 构建，启动器会先备份再安装适配扩展。若提示 WeFlow 仍在托盘运行，右键其托盘图标选择「退出」，再运行启动脚本。
4. 在桥接面板的「模型工作室 → 主模型」填入服务地址、模型名称和 API Key，保存设置。用另一个微信账号给机器人发一条文字私聊，确认对方能收到回复。使用朋友圈时，再到「朋友圈轮询」启用所需动作并核对机器人当前登录账号的微信 ID。

桥接面板默认位于 `http://127.0.0.1:8766`，AstrBot 面板默认位于 `http://127.0.0.1:6185`。关闭浏览器后可双击 **打开面板.bat** 重新进入。AstrBot 首次登录的用户名为 `astrbot`，随机密码保存在 `portable/runtime/astrbot-instance/dashboard-login.txt`。

如需校验下载，在 PowerShell 中运行 `Get-FileHash .\wechatbot-v7.0.0-portable.zip -Algorithm SHA256`。v7.0.0 发布附件的 SHA-256 为 `b5acdc47d765b29388da44c4141ee7a2929fd4cbbc8e60d44a75be2ed882672d`。

## 语音与系统组件

使用微信语音需要 VB-Cable、正确的录放音设备和可用的语音服务。首次启动时若开启语音但未检测到驱动，启动器会下载并核验官方安装器。在 Windows 确认提示后，点击 **Install Driver**，按提示重启，再到「发送与设备」检查设备。也可稍后双击 **安装语音驱动.bat** 单独安装。跳过语音驱动后，文字和图片功能仍可使用。

若系统缺少 Microsoft Visual C++ x64 运行库，首次启动可能需要联网下载并确认安装。**离线启动.bat** 使用包内的程序依赖，在线模型和媒体服务仍需网络。

## 备份、移动与升级

从工作台选择「完全退出」后再复制文件或更换版本。要迁移现有配置和历史，先保存以下位置。另行指定了数据库或素材路径时，也要备份实际目录。

| 位置（相对解压目录） | 内容 |
| --- | --- |
| `wechat-weflow-bridge-ob11/config.json` | 连接设置、角色、模型参数和密钥 |
| `wechat-weflow-bridge-ob11/data/` | 本地记忆、身份映射、发送记录和素材 |
| `portable/runtime/astrbot-instance/` | AstrBot 实例、会话、插件数据和面板密码 |

升级时把新包解压到另一个目录，再迁移需要保留的数据。启动器会尝试退出可核验的旧服务，原目录中的历史不会自动迁入。配置、数据库和密码文件均应由本人保管。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 双击后启动失败 | 查看 `portable/runtime/startup-error.txt` 里的失败阶段和错误文字。若缺少包内依赖，重新完整解压 Release 附件。 |
| 面板打开，但收不到消息 | 检查微信与 WeFlow 是否使用同一账号、WeFlow 数据库是否就绪，以及 API 令牌和主动推送开关。若已收到消息但没有回复，再检查主模型配置与额度。 |
| 微信界面操作失败 | 在「发送与设备」查看实际微信构建。已准备好便携环境时，可运行 **收集只读诊断.bat**，在 `portable/runtime/只读诊断报告.json` 查看模块与监听状态。[微信 UIA 兼容性](../docs/微信UIA兼容性.md) |

各项面板设置的名称、作用和生效条件见[配置字段](../docs/配置字段.md)。运行依赖的来源和许可见[第三方运行组件](LICENSES.md)。
